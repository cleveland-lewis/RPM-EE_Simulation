# Scientific Methods

This document maps the code parameters in the RPM-EE model to their corresponding theoretical constructs and preregistered hypotheses.

## Parameter Mapping

| Parameter | Construct | Description |
| --- | --- | --- |
| `attention_span` | Attention | The duration for which the model can maintain focus on a single task. |
| `memory_capacity` | Memory | The number of items the model can hold in its working memory. |
| `emotional_reactivity` | Emotion | The magnitude of the model's emotional response to a stimulus. |

## Hypotheses

### H1: Attention and Memory

A decrease in `attention_span` will lead to a decrease in `memory_capacity`.

### H2: Emotion and Memory

An increase in `emotional_reactivity` will lead to a decrease in `memory_capacity`.
